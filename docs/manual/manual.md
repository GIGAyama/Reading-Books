# どくしょ ちょきんばこ の つかいかた

このページは、よんだ本を バーコードで きろくして、さつ<ruby>数<rt>すう</rt></ruby>・ページ<ruby>数<rt>すう</rt></ruby>・きんがくを ためていく アプリ「どくしょ ちょきんばこ」の つかいかたです。はじめて ひらく人が、この ページだけで さいごまで つかえるように、がめんの しゃしんと 見くらべながら 上から じゅんに よんで ください。

## どくしょ ちょきんばこで できること

この しょうでは、この アプリが <ruby>何<rt>なに</rt></ruby>を する ものか、だれが つかう ものか、つかう まえに <ruby>用意<rt>ようい</rt></ruby>する ものを せつめいします。

### どんな アプリか

よんだ本の うらに ある バーコードを カメラで よむと、本の なまえ・かいた人・ページ<ruby>数<rt>すう</rt></ruby>・ねだんが じどうで 入ります。それを 1さつずつ きろくして いくと、よんだ本の かず・ページ<ruby>数<rt>すう</rt></ruby>・きんがくが「ちょきん」のように たまって いきます。

つかうのは 小学校の 子どもです。1年生から 6年生まで つかえます。先生や おうちの人は、さいしょに アプリを 入れる ときと、きろくを <ruby>紙<rt>かみ</rt></ruby>に いんさつする ときに 手つだって ください。

できる ことは 大きく わけて 6つ あります。

- 本を きろくする（カメラ・ばんごう・じぶんで かく の 3つの やりかた）
- よんだ本の リストを 見る・さがす
- ほしと かんそうを つける
- 月の もくひょうと スタンプちょう
- どくしょの ふりかえりを グラフで 見る
- きろくを ファイルに のこす・<ruby>紙<rt>かみ</rt></ruby>に いんさつする

![きろくが たまった ホームがめん](images/01-home-full.png)

ホームがめんです。上から ちょきん・こんげつの ようす・きろくの ボタンと つづきます。

### つかう まえに <ruby>用意<rt>ようい</rt></ruby>する もの

つぎの 3つを <ruby>用意<rt>ようい</rt></ruby>して ください。

- カメラの ついた タブレット、スマートフォン、または パソコン。カメラが なくても、ばんごうを 入れたり じぶんで かいたり して きろくできます
- ブラウザ（Chrome、Edge、Safari の どれか）
- アプリの アドレス https://reading-books.giga-school.com/

なまえや パスワードは いりません。アカウントを つくる ことも ありません。

インターネットは、さいしょに ひらく ときと、本の じょうほうを しらべる ときだけ つかいます。それ いがいは つながって いなくても つかえます。

### きろくは どこに のこるか（インターネットには おくらない）

よんだ本の きろくは、つかって いる きかいの 中だけに のこります。インターネットへ おくる ことは ありません。なまえや クラスを 入れる ところも ありません。

だから、べつの きかいで ひらいても きろくは 出て きません。きかいを かえる ときは「データを のこす・よみこむ」の しょうを 見て ください。

## はじめて ひらく ときに する こと（さいしょの 1<ruby>回<rt>かい</rt></ruby>だけ）

さいしょの 1<ruby>回<rt>かい</rt></ruby>だけ やって おく ことが 2つ あります。1つめは かならず やります。2つめは やらなくても つかえますが、やって おくと べんりです。

### ブラウザで アドレスを ひらく

ブラウザを ひらいて、いちばん 上の アドレスの ところに つぎの ように 入れて ください。

https://reading-books.giga-school.com/

すぐに ホームがめんが 出ます。まだ <ruby>何<rt>なに</rt></ruby>も きろくして いない ときは「まだ きろくが ありません」と 出ます。これで ただしく ひらけて います。

さいしょの 1<ruby>回<rt>かい</rt></ruby>は、かならず インターネットに つながった ところで ひらいて ください。その ときに アプリの 中みが きかいの 中に 入ります。2<ruby>回<rt>かい</rt></ruby>めからは、つながって いなくても ひらけます。

![はじめて ひらいた ホームがめん](images/02-home-empty.png)

まだ 1さつも ないので、ぜんぶ 0 に なって います。

### ホームがめんに アプリとして 入れて おく（先生に 手つだって もらう）

ホームがめんに 入れて おくと、ブラウザの バーが きえて がめんが ひろく なり、アイコンを 1<ruby>回<rt>かい</rt></ruby> おすだけで ひらけます。iPad では、きろくが きえにくく なる よい ことも あります。

入れかたは きかいに よって ちがいます。

Chromebook・Windows・Android（Chrome / Edge）の 手じゅん:

1. 下の「きろく」を おします。
2. 「アプリとして インストール」を おします。
3. ブラウザが 出す かくにんの がめんで「インストール」を おします。

![きろくの がめんの インストールの 行](images/03-install-menu.png)

赤い わくの <ruby>行<rt>ぎょう</rt></ruby>を おします。

「アプリとして インストール」の <ruby>行<rt>ぎょう</rt></ruby>が 見あたらない ときは、ブラウザが「入れられます」と おしえて きて いない ときです。ブラウザの 右上の <ruby>点<rt>てん</rt></ruby>が 3つ ならんだ ボタンを おして、「アプリをインストール」か「ホーム<ruby>画面<rt>がめん</rt></ruby>に<ruby>追加<rt>ついか</rt></ruby>」を えらんで ください。

iPad・iPhone（Safari）の 手じゅん:

1. 下の「きろく」を おします。
2. 「アプリとして インストール」を おします。やりかたの あんないが 出ます。
3. Safari の 下（iPad では 右上）に ある <ruby>共有<rt>きょうゆう</rt></ruby>の ボタン（<ruby>四角<rt>しかく</rt></ruby>から 上へ <ruby>矢<rt>や</rt></ruby>じるしが 出て いる しるし）を おします。
4. 下の ほうに ある「ホーム<ruby>画面<rt>がめん</rt></ruby>に<ruby>追加<rt>ついか</rt></ruby>」を おします。
5. 右上の「<ruby>追加<rt>ついか</rt></ruby>」を おします。

![アプリとして つかう の あんない](images/04-install-dialog.png)

「アプリとして インストール」を おすと 出る あんないです。

【！】おぼえて おいて ほしい こと:

- 入れなくても、ブラウザの ままで ぜんぶの きのうが つかえます。
- iPad の Safari は、7日 いじょう 1<ruby>回<rt>かい</rt></ruby>も ひらかないと のこした きろくが きえる ことが あります。ホームがめんに 入れて おくと おきにくく なります。
- ホームがめんに 入れても、きろくは その きかいの 中に のこった ままです。べつの きかいには うつりません。

## ホームがめんの みかた

ホームがめんには、上の おび・ちょきん・こんげつの ようす・きろくの ボタン・さいきんの 本・下の タブが あります。どこに <ruby>何<rt>なに</rt></ruby>が あるかを おぼえて おくと まよいません。

### 上の おびと ちょきんの かず

いちばん 上の こい 青い おびには、まん中に「どくしょ ちょきんばこ」、右に「？」の ボタンが あります。ほかの がめんに いると、左に「もどる」の ボタンが 出ます。

その 下の「いままでに よんだ本の ちょきん」には、3つの かずが 出ます。

- よんだ本のかず … いままでに きろくした 本の さつ<ruby>数<rt>すう</rt></ruby>
- よんだページ … ぜんぶの 本の ページ<ruby>数<rt>すう</rt></ruby>を たした かず
- ごうけいきんがく … ぜんぶの 本の ねだんを たした かず

つぎの「こんげつの ようす」には、この 月に よんだ さつ<ruby>数<rt>すう</rt></ruby>と もくひょうが「8 / 10 さつ」の ように 出て、下の ぼうが のびて いきます。もくひょうに とどくと ぼうが 金いろに なります。

![ホームがめんの 上の ほう](images/05-home-top.png)

右上の 赤い わくが「？」の ボタンです。

### 本を きろくする 3つの ボタン

「本を きろくする」の 青い カードに、ボタンが 3つ ならんで います。上から、つかって ほしい じゅんに ならんで います。

- カメラで バーコードを よむ … いちばん かんたん。本の うらの バーコードに カメラを むけます
- 本のばんごう(ISBN)で さがす … カメラが つかえない ときに、バーコードの 下の すうじを 入れます
- じぶんで かいて きろくする … 本の なまえと ページ<ruby>数<rt>すう</rt></ruby>を じぶんで かきます

![本を きろくする 3つの ボタン](images/06-home-buttons.png)

どれを おしても、さいごは おなじ「本を きろくする」の がめんに つきます。

その 下の「さいきん きろくした本」には、あたらしい じゅんに 3さつ 出ます。本を おすと「本の くわしく」が ひらきます。右の「ぜんぶ みる」を おすと リストに うつります。

### 下の 4つの タブと もどりかた

がめんの いちばん 下に タブが 4つ あります。いま ひらいて いる タブは 金いろに なります。

- ホーム … この がめん
- リスト … よんだ本の いちらん
- スタンプ … 月の もくひょうと スタンプちょう
- きろく … ふりかえり・データを のこす・つかいかた・せってい

![下の 4つの タブ](images/07-nav-tabs.png)

タブを おすと、その がめんに かわります。

タブの 中から べつの がめんに 入ると、下の タブが「まえの がめんに もどる」の ボタンに かわります。1つ まえに もどる やりかたは 3つ あります。

- 上の おびの 左に ある「もどる」を おす
- いちばん 下の「まえの がめんに もどる」を おす
- がめんの 左右の はしから まん中へ ゆびを すべらせる。パソコンでは キーボードの Esc キーでも もどれます

### パソコンや 大きい タブレットで ひらいた とき

がめんが ひろい ときは、ホームがめんが 左右 2れつに なります。左に ちょきんと こんげつの ようす、右に きろくの ボタンと さいきんの 本が ならびます。出て いる ものと おしかたは おなじです。

![パソコンで ひらいた ホームがめん](images/08-desktop.png)

ひろい がめんでは 2れつに ならびます。

### 「？」を おすと 出る つかいかた

上の おびの 右に ある「？」を おすと、みじかい「つかいかた」が 出ます。バーコードの よみかた、ばんごうの 入れかた、もどりかた、ほしの つけかた、データの のこしかたが 1つずつ カードに なって います。「きろく」の タブの「つかいかた」からも おなじ がめんに いけます。

![つかいかたの がめん](images/09-help-screen.png)

こまった ときに、まず ここを 見て ください。

## カメラで バーコードを よんで きろくする

いちばん かんたんな きろくの しかたです。本の うらの バーコードに カメラを むけるだけで、本の なまえなどが じどうで 入ります。

### よむのは 978で はじまる バーコード

日本の 本の うらには、バーコードが 2つ ならんで います。上の 978（または 979）で はじまる ほうが 本の ばんごうです。すぐ 下に ある 192（または 191）で はじまる ほうは ねだんの バーコードなので、この アプリでは つかいません。

まちがえて 下の ほうを よむと、がめんに「それは ねだんの バーコードだよ。上の 978 の ほうを よんでね」と 出ます。その ときは、<ruby>少<rt>すこ</rt></ruby>し 上に ずらして 978 の ほうを わくに 入れて ください。

### カメラで よみとる 手じゅん

1. ホームの「カメラで バーコードを よむ」を おします。
2. 「カメラを つかって いいですか」の ような かくにんが 出たら「きょか」を おします。これは ブラウザが 出す ふつうの かくにんで、あんしんして よい ものです。
3. まん中に 金いろの わくと「本の うらの 978 ではじまる バーコードに あわせてね」の 文が 出たら、カメラの じゅんびが できて います。
4. 本の うらの 978 の バーコードを わくに 入れます。本から 20 センチ くらい はなすと よく よめます。
5. よめると「よめました！」と 出て、ピッと 音が なり、じどうで「本を きろくする」の がめんに かわります。

![カメラで よみとる がめん](images/10-scan.png)

下の 978 ではない バーコードを よむと、この ように おしえて くれます。

6. 「本を きろくする」の がめんで、「しらべています…」の あとに「みつけた！」と 本の なまえが 出るのを まちます。本の なまえ・かいた人・ページ・ねだんが 入ります。入って いない らんが あれば、本を 見て かきたします。ページと ねだんが わからなかった ときは、その らんが 赤く なり「本を みて かいてね」と 出ます。
7. おもしろさの ほしと かんそうを つけます。つけなくても きろくできます。
8. 下の「この本を きろくする！」を おします。「きろく したよ！」と 出て ホームに もどります。

![みつけた！と 出た がめん](images/11-entry-found.png)

赤い わくの ところに、みつかった 本の なまえが 出ます。

### カメラが つかえない ときは「ばんごうで いれる」

カメラの がめんの 下に、ボタンが 2つ あります。「ばんごうで いれる」を おすと、カメラを やめて「本を きろくする」の がめんに うつり、バーコードの 下の すうじを じぶんで 入れられます。「やめる」を おすと ホームに もどります。

くらい ところで ライトが つかえる きかいでは、「ライト」の ボタンも 出ます。おすたびに ライトが ついたり きえたり します。

![ばんごうで いれる を おした あとの がめん](images/12-entry-from-scan.png)

上の らんに、バーコードの 下の すうじを 入れます。

【！】おぼえて おいて ほしい こと:

- カメラは、この がめんを ひらいて いる あいだだけ うごきます。ほかの がめんに うつると じどうで <ruby>止<rt>と</rt></ruby>まります。
- 本の じょうほうを しらべる ときだけ インターネットを つかいます。おくって いるのは 本の ばんごうだけで、きかいの 中の きろくは おくりません。
- 本の じょうほうが 6びょう たっても そろわない ときは、わかった ところまでで 先に すすみます。のこりは 本を 見て かきたして ください。
- としょしつの 本は、バーコードに シールが はって ある ことが あります。その ときは「ばんごうで いれる」を つかって ください。

## 本の ばんごう（ISBN）を 入れて さがす

カメラが つかえない ときや、うまく よめない ときは、バーコードの 下に かいて ある すうじを じぶんで 入れて さがせます。

### ばんごうを 入れて「さがす」を おす

1. ホームの「本のばんごう(ISBN)で さがす」を おします。
2. いちばん 上の「本のばんごう(ISBN)で さがす」の らんに、バーコードの 下の すうじを 入れます。978 から はじまる 13けたの すうじです。ハイフンは 入れなくて かまいません。
3. 右の「さがす」を おします。キーボードの Enter キーでも さがせます。
4. 「しらべています…」の あとに「みつけた！」と 出て、本の なまえ・かいた人・ページ・ねだんが 入ります。
5. のこりを かきたして「この本を きろくする！」を おします。

![ばんごうを 入れた ところ](images/13-isbn-typed.png)

赤い わくに すうじを 入れて、右の「さがす」を おします。

ふるい 本には、978 が つかない 10けたの ばんごうが かいて ある ことが あります。10けたの ままで 入れても、アプリが 13けたに なおして さがして くれます。しゃしんの 4834000826 は その れいです。

### みつからなかった とき

「みつかりませんでした。下の らんに じぶんで かいて きろく できます。」と 出る ことが あります。ばんごうは あって いるのに、しらべ先に その 本が のって いない ときや、インターネットに つながって いない ときです。

その ときは、そのまま 下の「本の じょうほう」の らんに、本の なまえと ページ<ruby>数<rt>すう</rt></ruby>を じぶんで かいて きろくして ください。

![みつからなかった とき の がめん](images/14-isbn-notfound.png)

赤い 文が 出ても、下の らんに かけば きろくできます。

### ばんごうが ちがう とき

「978で はじまる 13けたの すうじを いれてね」と 出た ときは、入れた すうじが 本の ばんごうの <ruby>形<rt>かたち</rt></ruby>に なって いません。けたが たりない、1けた まちがえて いる、192 の ほう（ねだんの バーコード）の すうじを 入れて いる、の どれかです。もういちど 本を 見て 入れなおして ください。

![ばんごうが ちがう とき の がめん](images/15-isbn-invalid.png)

らんが 赤く なり、上の 文が 出ます。

【！】おぼえて おいて ほしい こと:

- しらべ先は 3つ あります（openBD・Google Books・<ruby>国立国会図書館<rt>こくりつこっかいとしょかん</rt></ruby>サーチ）。3つ ぜんぶに きいて、そろった ものから つかいます。
- ページと ねだんが しらべ先に なかった ときは、その らんだけ 赤く なります。本の おくづけを 見て かいて ください。
- おなじ 本を もう 1<ruby>回<rt>かい</rt></ruby> さがしても、きろくは ふえません。ふえるのは「この本を きろくする！」を おした ときだけです。

## じぶんで かいて きろくする

バーコードの ない 本、ふるい 本、みつからなかった 本は、じぶんで かいて きろくします。かならず 入れるのは 2つだけです。

### かならず 入れる ところは 2つ

「本の じょうほう」の 中で、＊の ついた らんは かならず 入れます。

- 本の なまえ ＊
- ページ ＊

ほかの らんは 入れなくても きろくできます。

- かいた ひと … 入れないと「ふめい」に なります
- ねだん(えん) … 入れないと 0円 として かぞえます
- おもしろさ … ほしを 1つから 5つまで。あとから かえられます
- かんそう … 200字まで。あとから かきたせます

なまえや ページを 入れずに「この本を きろくする！」を おすと、「本の なまえを いれてね」「ページすうを いれてね」と 出て、その らんが 赤く なります。

![なまえを 入れずに おした とき](images/16-entry-required.png)

赤く なった らんを 入れれば、きろくできます。

### 本の じょうほうを 入れて きろくする

1. ホームの「じぶんで かいて きろくする」を おします。「本を きろくする」の がめんが ひらき、「本の なまえ」の らんに カーソルが 入ります。
2. 本の なまえを 入れます。
3. かいた ひとを 入れます（入れなくても かまいません）。
4. ページと ねだん(えん)を すうじで 入れます。
5. おもしろさの ほしを おします。おなじ ほしを もう 1<ruby>回<rt>かい</rt></ruby> おすと 0に もどります。
6. かんそうを かきます（かかなくても かまいません）。
7. 「この本を きろくする！」を おします。

![ぜんぶ 入れた ところ](images/17-entry-filled.png)

赤い わくの ボタンで きろくします。

おすと「きろく したよ！」と 本の なまえが 出て、ホームに もどります。ちょきんの かずが ふえて、「さいきん きろくした本」の いちばん 上に その 本が ならびます。

![きろく したよ！の おいわい](images/19-recorded.png)

きろく できると、この ように 出ます。

### おなじ本が あります と 出た とき

- ぜんぶの さつ<ruby>数<rt>すう</rt></ruby>・ページ<ruby>数<rt>すう</rt></ruby>・きんがく
- 1さつずつの ひょう（ばんごう・よんだ日・本の なまえと かんそう・かいた人・ページ・ねだん・ほし）

![いんさつの できあがり](images/39-print-sheet.png)

A4 たて 1まいに、この ように 出ます。

【！】おぼえて おいて ほしい こと:

- 本が <ruby>多<rt>おお</rt></ruby>くて 1まいに 入らない ときは、2まいめに つづきます。ひょうの 見出しの <ruby>行<rt>ぎょう</rt></ruby>は 2まいめにも 出ます。
- 1さつの <ruby>行<rt>ぎょう</rt></ruby>が とちゅうで <ruby>切<rt>き</rt></ruby>れる ことは ありません。
- <ruby>横<rt>よこ</rt></ruby>に <ruby>切<rt>き</rt></ruby>れて 見える ときは、いんさつの がめんの「<ruby>用紙<rt>ようし</rt></ruby>」が A4、「<ruby>向<rt>む</rt></ruby>き」が たて に なって いるか たしかめて ください。
- パソコンでは、キーボードの Ctrl と P を いっしょに おしても、おなじ ものが いんさつできます。

## おとの オン・オフと アプリの じょうほう

きろくした ときの ピッという 音や ファンファーレは、ならさない ように できます。アプリの バージョンも ここで 見られます。

### おとを ならす・ならさない

1. 下の「きろく」タブを おします。
2. 「おとを ならす」の <ruby>行<rt>ぎょう</rt></ruby>を おします。おすたびに、右はしが「オン」と「オフ」で 入れかわります。
3. 「オフ」に すると「おとを ならしません」と 出て、それからは 音が なりません。

![おとを オフに した ところ](images/40-sound-off.png)

右はしが「オフ」に なって いれば、音は なりません。

音の せっていは、きろくを ぜんぶ けしても のこります。

### このアプリについて（バージョン）

「きろく」の がめんの いちばん 下の「このアプリについて」には、つぎの ものが 出ます。

- バージョン … いま つかって いる アプリの <ruby>版<rt>はん</rt></ruby>の ばんごう
- がくしゅうログ … この きかいに のこって いる きろくの けんすう
- きろくは この きかいの なかだけに ほぞんされる、という せつめい

先生に「どの バージョンを つかって いますか」と きかれたら、ここを 見て こたえて ください。

## 【！！】きろくを ぜんぶ けす

しんきゅうで きかいを つぎの 人に わたす ときなど、きろくを ぜんぶ けしたい ときに つかいます。けした ものは もとに もどせないので、かならず 先に ほぞんして ください。

### けす まえに かならず ほぞんする

「きろく」タブの いちばん 下、赤い 文字の「きろくを ぜんぶ けす」を おすと、「ぜんぶ けす」の がめんが ひらきます。

この がめんには ボタンが 3つ あります。

- さきに ほぞんする … きろくを ファイルに のこします。「ファイルに ほぞんする」と おなじです
- ほんとうに ぜんぶ けす … けします
- やめる … <ruby>何<rt>なに</rt></ruby>も せずに もどります

![ぜんぶ けす の がめん](images/41-reset-screen.png)

上の わくが「さきに ほぞんする」、下の わくが けす ボタンです。

### ぜんぶ けす 手じゅん

1. 「さきに ほぞんする」を おして、ファイルを のこします。
2. 「ほんとうに ぜんぶ けす」を おします。
3. 「ほんとうに ぜんぶ けしますか？」と 出ます。もう 1<ruby>回<rt>かい</rt></ruby> たしかめて「ぜんぶ けす」を おします。
4. 「きろくを ぜんぶ けしました」と 出て、ホームに もどります。ちょきんは ぜんぶ 0に なります。

![けす まえの さいごの かくにん](images/42-reset-confirm.png)

ここで「ぜんぶ けす」を おすと、もどせません。

【！！】もっとも 気を つける こと:

- きえるのは、よんだ本の きろく・月ごとの もくひょう・おいわいずみの 月 の 3つです。
- 音の オン・オフの せっていは のこります。
- おなじ きかいに 入って いる ほかの <ruby>学習<rt>がくしゅう</rt></ruby>アプリの きろくは きえません。
- もとには もどせません。「さきに ほぞんする」を おして いれば、「データを のこす・よみこむ」から もどせます。

## うまく いかない とき

こまった ときは、まず ここを 見て ください。それでも なおらない ときの <ruby>聞<rt>き</rt></ruby>き先は、さいごに <ruby>書<rt>か</rt></ruby>いて あります。

### カメラが ひらかない・まっくろ

「カメラを つかう きょかが ありません」と 出た ときは、ブラウザが カメラを つかう ことを ゆるして いません。アドレスの 左の かぎの しるしを おして、「カメラ」を「<ruby>許可<rt>きょか</rt></ruby>」に して、もういちど ひらいて ください。Chromebook では、せっていの「プライバシーとセキュリティ」の「サイトの<ruby>設定<rt>せってい</rt></ruby>」の「カメラ」からも かえられます。

「カメラが みつかりませんでした」と 出た ときは、その きかいに カメラが ないか、ブラウザから 見えて いません。「ばんごうで いれる」で すうじを 入れて ください。

![カメラが みつからない とき](images/43-scan-nocamera.png)

この 文が 出たら、下の「ばんごうで いれる」を おします。

カメラの がめんが まっくろの ときは、ほかの アプリ（Meet など）が カメラを つかって いないか たしかめて ください。

### バーコードが よめない

- ピントが あわない … 本を 20 センチ くらい はなします。ちかづけすぎると よめません。
- くらい … 「ライト」の ボタンが あれば おします。まどの ほうを むくのも よい <ruby>方<rt>ほう</rt></ruby>ほうです。
- ひかって しまう … けいこうとうの まっすぐ 下を さけて、<ruby>少<rt>すこ</rt></ruby>し ななめに します。
- なんど やっても よめない … 「ばんごうで いれる」で、バーコードの 下の 978 から はじまる すうじを 入れます。
- 978 の バーコードが ない ふるい 本 … 「じぶんで かいて きろくする」で、なまえと ページ<ruby>数<rt>すう</rt></ruby>を 入れます。うらや おくづけに 10けたの ばんごうが あれば、それを 入れても さがせます。

### 本の じょうほうが 出てこない

「みつかりませんでした」と 出る ときは、しらべ先に その 本が のって いないか、学校の インターネットが しらべ先への つうしんを <ruby>止<rt>と</rt></ruby>めて います。「じぶんで かいて きろくする」で、なまえと ページ<ruby>数<rt>すう</rt></ruby>を 入れれば きろくできます。

先生へ。学校の フィルタリングで <ruby>止<rt>と</rt></ruby>まって いる ときは、この ページの 下に ある「学校で<ruby>使<rt>つか</rt></ruby>うときは」の ところに <ruby>書<rt>か</rt></ruby>いて ある アドレスを ゆるして ください。

### きろくが きえた

きろくは ブラウザごとに <ruby>分<rt>わ</rt></ruby>かれて います。つぎの ことを たしかめて ください。

- べつの ブラウザで ひらいて いないか（Chrome で 入れた きろくは Safari には 出ません）
- シークレットウィンドウで つかって いないか（とじると きえます）
- iPad で 7日 いじょう ひらいて いなかった か（ホームがめんに 入れて おくと おきにくく なります）
- ブラウザの「<ruby>閲覧履歴<rt>えつらんりれき</rt></ruby>データの<ruby>削除<rt>さくじょ</rt></ruby>」で サイトの データを けして いないか
- ふるい アドレス（gigayama.github.io/Reading-Books/）で つかって いないか。あたらしい アドレスとは きろくの おき<ruby>場<rt>ば</rt></ruby>が べつです

きえた きろくは アプリからは もどせません。ファイルに のこして あれば、「データを のこす・よみこむ」から もどせます。

### あたらしい バージョンが あります と 出た

アプリが あたらしく なると、がめんの 下に「あたらしい バージョンが あります」と 出ます。

- さいしんに する … あたらしい アプリに よみこみなおします。きろくは きえません。
- あとで … そのまま つかいつづけます。つぎに ひらいた ときに また 出ます。

![あたらしい バージョンの おしらせ](images/44-update-bar.png)

「さいしんに する」を おすと、あたらしく なります。

かんそうを かいて いる とちゅうなら、先に きろくして から「さいしんに する」を おして ください。

### インターネットに つながらない がめんが 出た

「いま インターネットに つながって いません」の がめんが 出た ときは、Wi-Fi を たしかめて「もういちど ためす」を おします。きろくは きかいの 中に のこって いるので、きえて いません。

さいしょの 1<ruby>回<rt>かい</rt></ruby>を インターネットに つながった ところで ひらいて いれば、2<ruby>回<rt>かい</rt></ruby>めからは つながって いなくても ホームは ひらけます。本の じょうほうを しらべる ことだけが できません。

### おとが ならない・うるさい

「きろく」タブの「おとを ならす」を 見て ください。右はしが「オフ」なら 音は なりません。おすと「オン」に なります。きかいの 音の 大きさが 0に なって いないかも たしかめて ください。うごきが 気に なる ときは、きかいの「<ruby>視差効果<rt>しさこうか</rt></ruby>を<ruby>減<rt>へ</rt></ruby>らす」を オンに すると、<ruby>紙<rt>かみ</rt></ruby>ふぶきが 出なく なります。

### それでも なおらない とき

まず、この アプリを おしえて くれた 先生や、学校の じょうほうの たんとうの 先生に <ruby>聞<rt>き</rt></ruby>いて ください。どの がめんで、<ruby>何<rt>なに</rt></ruby>を おして、<ruby>何<rt>なん</rt></ruby>と 出たかを つたえると、はやく わかります。
